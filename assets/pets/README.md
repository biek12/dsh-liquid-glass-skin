# 陪伴宠物素材

三款角色于 2026-10-23 使用 AI 图像生成工具制作，并为插件整理了透明素材：糯米（奶油小猫）、月白（云朵小狐）与泡泡（蓝色小鲸）。素材随本项目以 MIT 许可分发。

- 根目录的 PNG 用于角色选择。
- `rig/*-base.png` 用于实时骨骼动画。
- `rig/*-closed.png` 用于眨眼。

当前实现通过 `src/pets/rig.js` 与 `rig-gpu.js` 连续驱动角色，支持待机、回应、拖拽及减少动态效果。旧版逐帧图集与生成中间文件已退出源码树。修改素材后，请运行 `npm test` 并在真实 DSH 中检查透明边缘、拖拽和气泡布局。
