# DSH Liquid Glass

为本机 **DSH Desktop Beta 2.0.18-beta.1 / DSH 0.2.1-rc.2** 编写的 Liquid Glass 皮肤与会话目录扩展。当前版本 **0.8.0**。

本版覆盖原生侧栏上半部、两列导航、主界面容器、工具栏和新会话主页；目录功能可独立保留。原生动态状态 class 不再影响皮肤匹配，鼠标进出只改变绘制状态，保持布局与标题宽度稳定。

## 0.8.0 更新

- 完整接入原生运行中状态栏：在同一位置替换默认图标和“深度求索中，用时…”文字，显示轮换圆点、渐变状态文字、独立灰色计时，以及实际等待超过十秒时的“暂未响应”提示。
- 状态直接订阅当前会话的 `uiConversation.binding(sessionId).target('chat')`：按真实最新区块和运行中工具切换“正在思考 / 正在准备工具调用 / 正在调用工具 / 正在写回答”，文案至少保持一秒以减少闪烁。
- 移植参考实现的三种加载动画（弹跳、三线运动、四点交换位置），每十秒切换其他形态；切换文案使用原实现的双副本位移、模糊和宽度过渡，计时从当前轮次的真实开始时间计算。
- 系统减少动态效果、关闭动效与关闭状态动效时使用静态呈现。完成、切换会话和停用主题时释放订阅、计时器、动画与尺寸观察，恢复宿主状态栏。
- 数据尚未就绪时保留原生状态栏，不构造会话事件。按用户要求仅构建安装，实机效果交由人工验收。

## 0.7.2 更新

## 已确认的需求

- 工作区保持现有 DSH 工作区，在每个工作区下建立多层子目录。
- 一个会话只属于一个目录，支持拖拽归类和同级排序。
- 目录可跨层移动；不允许移入自身、子孙目录或其他工作区。
- 图标 / Emoji、颜色、标签、收藏、状态全部由用户手动设置。
- 状态包括：无状态、未开始、进行中、已完成、搁置。与 Agent 的实时运行状态互不关联。
- 删除目录时，把直接子目录和会话移到上一级，保留聊天记录。
- 接近 Apple 的视觉层次：玻璃用于导航和控件，正文保持清晰；深浅色跟随 DSH 的内置外观偏好。DSH 外观设置为“系统”时随系统切换。

## 使用

- 悬停工作区或目录，点击 `+` 新建子目录。
- 目录或会话右侧 `···` 打开按钮旁小菜单；右键则在鼠标位置打开。菜单不遮罩页面，支持方向键、Esc 和点击外部关闭。选择“标记与移动”设置图标、状态、颜色、标签、收藏与位置。
- 目录菜单提供重命名、新建子目录、标记与移动、删除目录。删除前确认，仅移除该目录，直接子目录和会话移到上一级。
- 工作区菜单提供重命名、子目录与移除工作区。移除调用原生 API，保留磁盘文件、聊天记录和独立标记；会话仍可在原生管理视图中查看。
- 会话菜单提供重命名、置顶/取消置顶、分叉、复制 Session ID、标记与移动、归档及一步撤销。置顶沿用 DSH 原生 pinnedSessionIds，保持原目录归属并优先显示，不产生重复条目。分叉调用原生完整轮次分叉，成功后尝试归入源会话的虚拟目录并打开；不存在完整轮次、迁移要求和归类失败会分别提示。
- 会话下方使用青蓝至淡紫的细线，从中心向两侧展开；深色模式提高亮度，保持文字和按钮宽度稳定。
- 归档使用原生能力；正在运行的会话会提示先停止，不会自动停止 Agent。
- 不再拼出“未归类会话”分组，只显示工作区注册表内的会话，避免把未归属的子 Agent 对话算入主列表。
- 展开和收起使用 220ms 高度过渡；系统启用减少动态效果时取消动画。
- 搜索图标按需展开搜索框，保留更多工作区高度。
- 拖到目录行中间：移入该目录。拖到同类条目行的上、下边缘：调整同级顺序。
- 拖到工作区行：移到此工作区根目录；会话和目录只能在原工作区内移动。
- 搜索支持目录名、会话标题和标签；筛选支持状态、标签、颜色、收藏。
- 筛选期间禁止拖动，清除筛选后恢复完整结构和排序。
- 键盘：方向键浏览，Enter / Space 打开或折叠，F2 编辑当前目录或会话，Delete 打开当前目录的删除确认。
- 侧栏底部“返回默认”恢复原始侧栏，使用原有工作区创建、归档、分叉等功能；点击“返回目录树”可返回增强目录。
- 打开输入框的模型菜单，在“推理等级”下拖动滑条；方向键、Home、End 可调节档位。右键滑条或按 Shift+F10 打开动画与刻度设置。
- 设置 → 通用 → 外观：选择 Liquid Glass。选择原生浅色、深色、系统或同一外观区中的其他皮肤时，本皮肤退出。
- 设置 → Liquid Glass：独立主题设置页，提供「明亮 / 暗黑 / 跟随系统」原生外观模式切换（与 DSH 共用持久化设置，切换时保留本皮肤），并可调节通透磨砂 / 实色材质、舒适 / 紧凑密度、行内标签、目录计数、流动 / 轻柔 / 关闭动效、主页光球、状态扫光及悬停光线。皮肤与目录树可独立开关，设置即时保存。恢复外观默认不会清空目录分类、标记或改变启用状态。系统减少动态效果优先于主题设置。

## 本机安装与皮肤市场

发布包为 `releases/dsh-liquid-glass-0.8.0.tgz`，包含预编译 Host 和 Client，无额外运行时依赖。

此机器使用 DSH 支持的 Cordis 本地文件入口安装，目录为 `~/.dsh-beta/local-plugins/dsh-liquid-glass/0.8.0`。活动 desktop Profile 的 `cordis.patch.yml` 中，`liquid-glass-local` 指向该版本的 `lib/index.js`。具体位置与包校验值记录在 `INSTALLATION.json`。升级不改原有依赖锁文件或包龄策略；操作前备份 Profile 补丁及独立分类数据。

停用本机安装：在 DSH 插件管理中停用 `liquid-glass-local`，或从补丁中移除该条目后重启。插件停用会恢复原始界面，分类数据保留。通过本地文件入口安装的版本，不适用 `dsh plugin remove dsh-liquid-glass` 的 bundle 卸载命令。

按 [dsh-liang-skin](https://github.com/kingOfSoySauce/dsh-liang-skin) 的原生外观接入方式，加入 Liquid Glass 外观入口、全局样式及主页呈现。选择本皮肤时触发当前原生外观按钮，通知参考皮肤退出；选择同一区域内其他外观时退出本皮肤。另监听其他皮肤的 body 标记，以处理部分从市场直接启用的皮肤。这是展示层切换，不会卸载其他插件，也不能保证识别所有第三方皮肤。

[dsh-skin-market](https://github.com/kingOfSoySauce/dsh-skin-market) 使用受审核的皮肤注册表，没有任意本地皮肤注册接口。正式出现在该市场中，需要公开 GitHub 仓库及提交皮肤收录；当前没有发布仓库或向市场提交 PR，也没有改写市场内置目录。**本机已安装不等于已在市场上架。**

## 数据与实现

Host 使用公开的 `storageDomain` 服务打开 `liquid_glass` 独立领域，并通过 `webServer` 注册 `/plugins/dsh-liquid-glass/v1/state`。每次更改校验工作区的真实会话成员关系、目录结构及 revision；落盘成功后才更新客户端。多个窗口冲突时返回最新数据并提示重试，禁止静默覆盖。

Client 通过公开的 `sidebar.workspaces` 插槽注册优先级为 -20 的目录视图。原始条目继续保留；停用新目录时恢复原条目。皮肤通过 `sidebar.brand.name` 与 `conversation.hero.brand.mark` 插槽定制品牌，并向原生 Hero 的空 body 添加可清理的标题内容，保留原生输入框与工作区选择器。原生 CSS 使用语义模块后缀定位，不硬编码构建哈希。侧栏外壳去掉顶部圆角边框。主页不展示 LIQUID GLASS 字样；玻璃图标使用多层流体光场、旋转光带、倾斜轨道、独立光晕和横纵悬浮路径。状态文字沿用原生活动 TextShimmer 标记，在对话区内以暖色高光持续扫动；已完成状态不播放，计时与可访问文字不变。系统减少动态效果时停用上述持续动画。主题使用 `theme.overrideTokens` 的浅色、深色成对覆盖，不修改内置主题偏好。插件卸载会移除所有注册、样式、轮询及 Token 覆盖。

会话工作路径、原始工作区归属、聊天正文、Agent 行为不由本插件修改。分类和标记不注入模型上下文。

## 验证与边界

```sh
npm test
npm run build
npm run test:installed
npm run pack:plugin
```

- 54 项领域、HTTP、目录源、原生操作适配、外观生命周期与组件交互测试，覆盖拖拽归类、目录嵌套、顺序、循环防护、跨工作区限制、元数据、并发冲突和写入失败。
- `test:installed` 直接读取本机安装包的 DomainFacility、SlotRegistry、ThemeRuntime 和 Cordis，验证预编译模块加载、持久化恢复、原始侧栏回退及卸载清理；使用临时存储，不修改活动 Profile。
- 已在浏览器验证三级目录创建、表单保存、手动标记、刷新恢复和浅深色视觉。HTML5 拖拽事件链通过组件测试验证；自动化浏览器的原生拖放未完成落点验证，仍需在 DSH 实机验收。
- 本主题是 Electron / Web 实现。公开窗口服务仅提供现有材质与布局信息，不提供 Apple 原生 Liquid Glass 的完整光学着色器；不承诺与系统原生控件逐像素相同。
- 目录增强限定既有工作区中的会话；归档会话及移除工作区后保留的会话，可在原生管理视图中查看。
- 支持最多 64 层嵌套、5,000 个目录、每项最多 12 个标签。

设计依据：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。
